# A 股因子库 · 交互式 Demo

可在浏览器里交互探索的 A 股多因子库（46 个因子，2020–2025）。纯静态页面，数据在浏览器内用 DuckDB-WASM 现场查询，无后端。

**在线访问**：https://fifamy.github.io/factor-lib-demo/

## 功能

- **单因子分析**：因子定义、Top-30 持仓、组合净值、KPI（年化/夏普/回撤/胜率/IC_IR）
- **多因子对比**：多个因子的指标、净值、IC 时序、相关性热力图并排比较
- **多因子合成**：自定义权重 + 阈值过滤合成打分，实时回测，含最优权重网格搜索
- **因子排行榜**：46 个因子按综合分（有效性 50% + 业绩 50%）排名，可勾选一键带入对比/合成

## 因子覆盖

- **市场交易信息**：动量、反转、波动、流动性、Beta
- **公司内生信息**：估值、盈利能力、盈利质量、成长、财务稳健、运营效率（41 个，来自 Wind PIT 财报）

## 口径

- 标准化：截面 rank → 正态分位数（对重尾稳健）
- 回测：top-N 等权、月末调仓、0.2% 双边成本，剔除 ST/停牌/退市
- 数据为已衍生的因子得分/回测结果，非原始行情明细

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 注：必须用 HTTP server 打开，不能直接双击 `index.html`（DuckDB-WASM 的 Worker 需要 HTTP 加载）。
